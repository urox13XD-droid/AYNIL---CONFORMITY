# AYNIL Conformity

Fiche de conformité de cadre pour la post-production : nom de production, réglages caméra,
ratio image, jusqu'à 4 images de référence, tous les éléments de texte déplaçables/redimensionnables
avec choix de police/taille/style/couleur. Export PNG, PDF (toujours en paysage), ou impression directe.

Projet indépendant de l'outil de schéma vidéo AYNIL.

## Développement

```bash
npm install
npm run dev
```

## Stack

Next.js (App Router) + TypeScript + Tailwind CSS.
